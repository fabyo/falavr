O **FalaVR** reúne ferramentas e conteúdo para aplicar traduções e dublagens em jogos compatíveis com Meta Quest.

## Download

Baixe o APK mais recente na página de [Releases](https://github.com/fabyo/falavr/releases/latest).

A versão **1.6** está disponível em [FalaVR-1.6-release.apk](https://github.com/fabyo/falavr/releases/download/v1.6/FalaVR-1.6-release.apk).

### Instalação

1. Baixe o APK pela página de Releases.
2. Instale-o no Meta Quest usando o método de instalação de APK de sua preferência.
3. Para obter ajuda com ADB, consulte [`ajuda_adb.zip`](ajuda_adb.zip).

## Arquivos deste repositório

- `capa.png`: imagem de apresentação do FalaVR.
- `ajuda_adb.zip`: material de ajuda relacionado ao ADB.
- O APK é publicado como arquivo da Release para download.
